At a glance

Same query. New domain. Who is still looking?

A naïvely fine-tuned MLLM localizes the moment on its training domain, but on an unseen domain it responds indiscriminately to memorized scene context and predicts the whole video. EVIDENT learns an entity-centric representation that consistently captures both person and book across frames, so the prediction stays grounded regardless of the domain.

Abstract

Ground the timestamp in the entities, not the scene.

Fine-tuning MLLMs for Video Temporal Grounding (VTG) often improves in-domain performance but degrades sharply under domain shift. We find that this failure is primarily driven not just by unseen query concepts, but by visual domain shift, which prevents the model from coupling its learned temporal localization knowledge with its inherent entity-attention capability.

We introduce EVIDENT, a parameter-efficient adaptation framework that anchors temporal grounding in the inherent entity-attention of pre-trained MLLMs by routing VTG adaptation through explicit visual entity evidence. EVIDENT consists of three components: (i) an Entity Bottleneck Adapter that transforms dense visual tokens into compact entity-level slots, (ii) an Entity-Binding Distillation loss that instills objectness priors into the semantically unstructured MLLM visual space, and (iii) an Entity-to-eVidence gating mechanism that steers the model to localize moments containing query-relevant entities.

Experiments on cross-domain VTG benchmarks show that EVIDENT consistently improves out-of-domain robustness while preserving competitive in-domain performance with modest parameter overhead.

Problem Analysis

Fine-tuning decouples attention from localization.

Pre-trained MLLMs already know where the entities are — across domains. Naïve VTG fine-tuning learns when, but that knowledge fails to inherit the entity-attention once the visual domain changes. We call this attention–localization decoupling. Analysis with Qwen2.5-VL-3B fine-tuned on Charades-STA and evaluated on QVHighlights; the same pattern holds for InternVL3-2B.

Entity-attention transfers. Zero-shot, patch–word similarity (e.g. “book”, “baby”) is strong on both Cha. and QVH.
Fine-tuning breaks it. ID–OOD gap of 19.8 (Cha.→QVH) and 33.4 (QVH→Cha.) R1@0.5.
Learned grounding stays home. Attention on G.T. frames rises substantially on ID, but only marginally on OOD.

Domain Gap Diagnosis

It's the visual gap, not the concept gap.

We split the OOD gap into a concept domain gap (are the query concepts unseen?) and a visual domain gap (how far are the videos from the source distribution?).

Concept gap is marginal. Seen vs. unseen query concepts: 44.0 vs. 40.7 (3.3-pt gap, Cha.→QVH).
Visual gap dominates. Top-20% visually similar: 52.8; bottom-20%: 39.1 (13.7-pt gap).
The model stops looking. On OOD, perturbing the G.T. interval hurts as much as a random one (−12.6 vs. −12.1). Suppressing non-G.T. frames helps (+4.6) — steering toward evidence recouples them.

Approach

EVIDence-grounded ENTity-attentive adaptation.

Three questions, three components: how to route adaptation through entities, what makes the entities meaningful, and how to use them as evidence for localization.

The roles are split on purpose: the slots only need to separate visual information at the entity level, while judging which entities matter for the query is left to the MLLM's pre-trained entity-attention — read out by E2V gating and by vision–language integration in the middle and later layers.

i EB Adapter

An Entity Bottleneck Adapter in the early decoder layers (L0–10) compresses each frame's 64 visual tokens into K=4 slots via slot attention, then reconstructs the tokens purely from slot features — added back residually, leaving the pre-trained path intact.

ii EB Distillation

The MLLM visual space alone is too entangled for slots to bind (near-uniform attention). Entity-Binding Distillation matches slot maps to per-frame DINOv2 K-means clusters via Hungarian matching and a BCE loss, so each slot binds to a coherent entity.

iii E2V Gating

Entity-to-eVidence gating scores each frame by the cosine similarity between its down-projected visual tokens and the query's subject and object tokens. Their product gt is high only where both co-occur, and scales the adapter's per-frame contribution.

Qualitative Analysis

What do the slots — and the gate — capture?

Trained only on Charades-STA, the EB Adapter decomposes scenes into people, objects, and backgrounds on unseen domains (QVHighlights, DiDeMo) without any domain-specific supervision.

EB Adapter attention. Each frame is masked by its highest-attending slot, for Cha. (ID), QVH (OOD), and DiDeMo (OOD) samples.

The gate lights up where the query's entities are.

E2V gating scores each frame by how strongly it matches each query entity. The per-entity scores follow the intervals in which each entity actually appears — person and glass rise together once they enter the frame, while an absent concept (zebra) stays flat.

Because the gate multiplies the subject and object scores, the adapter's contribution concentrates on frames where both entities co-occur — an inductive bias that holds across domains.

Consistent OOD gains. Competitive ID performance.
